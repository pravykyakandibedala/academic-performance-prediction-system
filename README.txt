ACADEMIC PERFORMANCE PREDICTION SYSTEM

1. INTRODUCTION
This project predicts students' academic performance
using machine learning techniques.

2. OBJECTIVE
- Predict students' final marks.
- Analyse student academic performance.
- Identify students who need improvement.
- Generate performance reports.

3. TECHNOLOGIES USED
- Python
- Visual Studio Code
- CSV Dataset
- Linear Regression
- Gradient Descent

4. INPUT DETAILS
- Student Name
- Study Hours
- Attendance Percentage
- Previous Marks

5. OUTPUT DETAILS
- Predicted Marks
- Performance Level
- Student Performance Report
- Performance Graph
- Saved Student Records

6. PERFORMANCE LEVELS
75 and above - Excellent
60 to 74 - Good
40 to 59 - Average
Below 40 - Needs Improvement

7. PROJECT MODULES
- Student Data Management
- Machine Learning Model
- Marks Prediction
- Performance Analysis
- Result Storage
- Performance Report

8. CONCLUSION
The Academic Performance Prediction System
helps analyse student performance and predicts
academic results using machine learning.
It can help identify students who need
additional academic support.
